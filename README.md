# Repositório de Atividades - Curso de Desenvolvimento Web Full Stack da Trybe

Este repositório contém as atividades realizadas durante o curso de Desenvolvimento Web Full Stack da Trybe em 2023. Aqui estão organizados os exercícios e projetos desenvolvidos ao longo do programa, que abrange desde fundamentos de programação até tópicos avançados de desenvolvimento front-end e back-end.

## Estrutura do Repositório

O repositório está dividido em pastas principais que representam os módulos do curso:

- **Fundamentos**: Introdução ao desenvolvimento web, incluindo HTML, CSS, JavaScript, Git e Unix.
- **Front-End**: Desenvolvimento de interfaces web utilizando tecnologias como React, JavaScript assíncrono, e testes automatizados com React Testing Library.
- **Back-End**: (Se aplicável, incluir descrição caso haja conteúdo relacionado a back-end).
- **Ciência da Computação**: (Se aplicável, incluir descrição caso haja conteúdo relacionado a ciência da computação).

Cada módulo é subdividido em dias de estudo, contendo exercícios e projetos práticos.

## Branches do Repositório

Os conteúdos deste repositório estão organizados em diferentes branches, cada uma representando um módulo ou conjunto de atividades específicas do curso. Para explorar os conteúdos em mais detalhes, acesse a seção de branches na página do GitHub deste repositório.

## Sobre o Curso

A Trybe é uma escola de desenvolvimento web que aborda as principais tecnologias do mercado e prepara os estudantes para se tornarem desenvolvedores Full Stack. O programa inclui mais de 1500 horas de conteúdo, cobrindo fundamentos de programação, front-end, back-end, ciência da computação, metodologias ágeis e habilidades comportamentais.

## Como Navegar no Repositório

1. Acesse as pastas correspondentes ao módulo e dia de estudo desejado.
2. Dentro de cada pasta, você encontrará os arquivos e projetos relacionados ao conteúdo estudado.
